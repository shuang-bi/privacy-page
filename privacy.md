# Privacy Policy

Last updated: October 11, 2026

Personal Agent is a private, single-user Telegram assistant built and used only by its owner. It is not available to the public.

## What data it accesses

With the owner's explicit consent through Google OAuth, Personal Agent accesses the owner's own Gmail messages and Google Calendar events in order to provide personal summaries and reminders.

## How data is used

Data is used only to generate responses for the owner within the owner's private Telegram chat. It is not used for advertising, is not sold, and is not shared with or transferred to any third party. Personal Agent does not use Google user data to develop or train generalized AI or machine learning models.

## Storage and retention

OAuth tokens are stored privately by the owner and are used only to access the owner's own Google account. Email and calendar content is processed on demand and is not kept in a public database or shared with anyone.

## Revoking access

The owner can revoke access at any time at https://myaccount.google.com/permissions
